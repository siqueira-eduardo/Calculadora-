# Calculadora em Java

Projeto introdutório desenvolvido para praticar lógica de programação e estruturas condicionais em Java.

## Funcionalidades

- Leitura de dois números informados pelo usuário.
- Escolha da operação matemática.
- Adição, subtração, multiplicação e divisão.
- Tratamento específico para divisão por zero.
- Mensagem para opção de operação inválida.

## Tecnologia

- Java
- Classe `Scanner` para entrada de dados.
- Estrutura `switch` para seleção da operação.

## Como executar

O código-fonte está atualmente no arquivo `Calc`, sem a extensão convencional `.java`. Para compilar com o fluxo padrão do Java, renomeie o arquivo para `Calculadora.java` e execute:

```bash
javac Calculadora.java
java Calculadora
```

É necessário ter o JDK instalado e disponível no PATH.

## Exemplo de uso

O programa solicita dois números e, em seguida, permite escolher uma operação:

1. Adição
2. Subtração
3. Multiplicação
4. Divisão

## Objetivo de aprendizagem

Praticar entrada e saída de dados, variáveis do tipo `double`, estruturas condicionais e tratamento de uma situação matemática inválida (divisão por zero).
